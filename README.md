# dsh-toolbox-gjkt

[![DeepSeek Harness](https://img.shields.io/badge/DeepSeek%20Harness-plugin-4B6EF5)](https://github.com/deepseek-ai)

**把 DSH 里零散的几类增强收进一个包：系统级任务通知、划词工具栏、自动续作、引用角标、远程巡检、长按 Alt 语音输入、Ctrl+点击文件用外部软件打开，外加四个 agent 工具——统一在「设置 → 工具箱」一个页面里开关，主对话框不放任何控件。**

它是干这个的：DSH 原生没有"后台任务跑完了但我不知道"的提醒，没有划词快捷操作，没有自动续作，没有可点的引用角标，终端输出中文还会因核心按 UTF-8 解码变成乱码。这个插件不改 DSH 核心，用客户端事件 + 系统提示词注入 + 标准 agent 工具把这些缺口补上，并且每一项都有独立开关——跟别的插件冲突时单独关掉就行，不用卸载整包。

**一个设置页，管全部：**

| 在哪 | 干什么 |
| --- | --- |
| 左下角 **设置 → 工具箱** | 独立的一级设置栏，八张可折叠卡片管所有开关和运行按钮 |
| 对话里直接说话 | agent 按需自动调用四个工具，或点「运行」按钮让它在当前会话跑 |

> 四个 agent 工具是**标准工具**（带 name + description 注入给模型），agent 遇到匹配场景会自己决定调用；设置页的「运行」按钮只是替你发一句话。任务通知、自动续作、语音快捷键走客户端事件/监听，跟 agent 工具是两套机制。

## 装

本项目是一个 DSH bundle（`dsh-toolbox-gjkt`）。通过 plugin_manager 从本地目录安装：

1. 在 DSH 里打开插件管理器，选"从本地安装 / install bundle"；
2. 指向本仓库目录（含 `package.json`）；
3. 装完启用，刷新 Web 界面；
4. 左下角 **设置 → 工具箱** 出现独立一栏即成功。

命令行等价做法（在能调用 `plugin_manager` 的会话里）：

```text
plugin_manager.install_bundle(target = "<本仓库绝对路径>")
```

> 语音输入（🎤）依赖官方 `@deepseek-ai/dsh-experimental-voice-input-bundle`，需先在插件管理器启用官方 bundle，并在首次使用时下载约 239 MB 本地模型。其余功能不依赖它。

## 设置页

左下角 **设置 → 工具箱**，与「通用 / 模型 / 账号」同级。八张卡片，默认全部折叠，点标题栏展开/收起：

| 卡片 | 内容 |
| --- | --- |
| 🎛️ 总开关 | 8 个 master 开关，每个能力一个，冲突时可单独关掉 |
| 🔔 任务通知 | 通知模式、提示音、子代理通知、点通知跳会话、自动续作、测试按钮 |
| ✂️ 划词工具栏 | 四个按钮启停、搜索引擎、翻译方向 |
| 🛠️ 工具 | 四个 agent 工具，每个一句大白话说明 +「运行」按钮 |
| 📡 远程巡检 | `ds-harness-remote` 状态、连接日志、保活看门狗、立即重连 |
| 🔖 引用角标 | 开关 + 角标格式（上标 / 数字 / 文字） |
| ⌨️ 快捷操作 | 长按 Alt 语音输入、静音 10 秒自动掐断、Ctrl+点击文件用外部软件打开——三个开关默认全关，按需手动开 |

所有 **Config 开关**走 DSH 原生配置（`.volatile()` 字段），改完即时生效、无需重启插件。几个例外（📡看门狗、Agent 等待提醒、⌨️ 卡里的三个快捷操作）走浏览器 localStorage，见[全部开关](#全部开关)。

> **快捷操作默认全关**：⌨️ 卡里的三个开关（长按 Alt 语音、静音掐断、Ctrl+点击外开）对全新安装默认关闭，按需手动开启。老用户此前已开启的设置会自动保留，不受这次改动影响。

## 客户端能力

### 任务通知

DSH 原生没有后台任务完成提醒。本插件监听 DSH 已转发到浏览器的会话生命周期事件（`api-session/status` / `api-session/error`），在任务**完成或出错那一刻**弹系统级通知（窗口最小化也看得到，带提示音），并且能读会话事件流，把产物文件（`deliverables/presented`）和工作流结束（`tool-workflow/run-end`）一起写进通知正文。

- **三种模式**：仅后台（窗口失焦时才弹）/ 始终（无视焦点）/ 从不。
- **一条铁律**：通知只在任务真正结束（running → idle）那一瞬触发。工具调用期间会话一直是 running，不会弹；跟窗口在前台后台无关。想验收就结束回合等通知，别在会话里干等。
- **子代理通知**：默认关（可开），避免子代理一多就刷屏。
- **提示音**：四种预设——经典双音 / 单音 / 三连音 / 静音；另按事件自动选音：出错=低沉下行、产物=清脆上行、工作流=三连音、普通完成用你选的预设。
- **点通知跳会话**：默认开，点通知气泡切回发出它的那个会话（`ctx.uiWorkspace.openSession`）。窗口开着或在后台有效；**最小化时网页通知拉不回窗口，DSH 关掉后通知也不会发**。
- **Agent 等我输入时提醒**：默认开。弹提问 / 授权确认 / 计划审阅时发一条系统通知（点它跳回对应会话），窗口开着或在后台（未最小化）都会提醒。靠官方界面的 `data-*` 标记识别，官方改了标记就可能失效。开关在通知卡里，存 localStorage。
- 工作流通知只拿到三态（完成/取消/出错），没有报错文本。

### 划词工具栏

对话里选中文字 → **右键**弹出四个按钮：搜索、翻译、复制、问 agent。纯客户端实现，不申请权限、不碰 host half。

- **搜索**：Bing / 百度 / Google 可选，新标签页打开。
- **翻译**：走百度翻译网页；自动模式按有无中文选 zh↔en，也可强制方向。
- **复制**：写剪贴板。
- **问 agent**：把选中文字填进输入框并附一句提示语。

> 为什么主入口用右键：DSH 原生的「引用」插件也响应划词且注册更早，同一时刻只显示第一个抢到浮层的插件。右键是引用不管的场景，稳定触发、两者不打架。

### 自动续作

任务产出产物或工作流结束、且窗口失焦时，自动往该会话追加一句用户消息「【自动续作】上一步已完成，请检查结果并继续。」让 agent 自己接着跑。默认关。

- 通过 `ctx.remote.session.prompt` 以 `queue` 模式追加，用 `requestId` 去重。
- 与系统通知**并存**：通知喊一声，续作替你接着聊。
- 设置页有「测试自动续作」按钮，跳过触发条件直接发那句气泡，用来验证链路。
- 代价：表现为一条用户气泡；页面关掉就不生效；goal 活跃时的让路逻辑本版未做。

### 引用角标

让模型在**有出处的事实后面**贴一个可点的角标，点开跳到来源（本地笔记或网页），提升可读性和直观性。默认关。

- 每步通过**系统提示词注入**（`ctx.systemPrompt.section`）告诉模型怎么贴，每轮重算、比 rules 文件强。
- 三种格式：**上标 `[¹]`** / 数字 `[1]` / 文字 `[source]`，超过 9 处退回普通数字。
- 来源写法：网页贴完整 URL；本地贴**正斜杠绝对路径**（如 `D:/path/to/note.md`），且必须先检索确认文件存在，不凭记忆编造；通用常识 / 推理不贴。
- 为什么用 Markdown 链接：本版 DSH 把标准脚注、内联 `<details>` 都渲染成纯文本、不可点，只有 Markdown 链接活着；点开是**跳走**（右侧栏预览 / 浏览器），不是就地弹出。

### 远程连接巡检

读 `ds-harness-remote` 的状态（同源 `/ds-harness-remote` 路由，浏览器自动带 cookie，无需 token），给一个只读状态面板 + 一个"立即重连"按钮。

- 显示：在线 / 重连中 / 已连接客户端 / 设备 / 账号 / 最近活跃 / 恢复截止时间 / 最近错误，以及「连接日志」按钮（最近 warn 级）。
- **保活看门狗**（默认开）：每 20 秒查一次，仅当离线且未在重连、非授权过期时请求一次重连，60 秒冷却。插件本身已有自动重连，这只是安全网。
- **插件修不了的**：token 过期、设备被撤销、残留凭据锁、DSH 进程崩溃——这些仍需手动重新配对/重启。
- 手机 App 侧的 TURN / RTT / ICE / 回落原因属于移动端诊断，主机端拿不到，卡片不显示也不编造。

### 长按 Alt 语音输入（push-to-talk）

借用官方语音输入的麦克风按钮，实现"按住说话、松开转写"。默认关。**需先启用官方语音输入 bundle 并下载好模型**（见[装](#装)）。

- 长按 `Alt` → 点官方"开始录音"；松开 → 点"停止并识别"，转写文字插入草稿（不自动发送）。
- 输错了**按一次 Ctrl+Z 整段撤回**（一段语音 = 一条撤销记录）。设了 180 ms 防误触延时、松开时如官方按钮还没渲染会有限重试。
- **静音 10 秒自动掐断**（默认关）：录音中连续 10 秒没说话，自动停止并转写，不用一直按着 Alt。靠读官方波形判断，官方改了波形结构后只是不再自动掐断，无害。开关在 ⌨️ 卡里，存 localStorage。
- 靠官方按钮的本地化 `aria-label` 定位（中英日西法德俄葡 8 语言），官方改了 DOM 结构就可能失效。
- Windows 上单独按 Alt 可能弹菜单栏；边界与反馈写在设置页 help 里。

### Ctrl+点击文件用外部软件打开

默认关（老用户此前开着的会保留）。普通点击文件还是在右侧栏预览；**按住 `Ctrl` 再点**就用系统默认应用（Word / Typora / 视频播放器 …… 取决于文件关联）打开：

- 覆盖两类：agent 生成的**文件卡片**（deliverables / present）、正文里的**文件链接**。
- 走 DSH 自己的 `session.openWorkspacePath`，不是另起进程。**路径会先解析成绝对路径**（相对路径先问 Host 要 `stat().absolutePath`，拿不到再用会话 cwd 拼）——这一步必须做对，否则把相对路径交给系统打开器时，`explorer.exe` 找不到文件就退回打开「文档」文件夹，看起来像"打开了资源管理器"。
- 靠文件卡片的 `data-presented-file` 标记和正文链接的 `title` 路径识别，官方改了这两处 DOM 就可能失效（只是 Ctrl+点击退回预览，无害）。开关在 ⌨️ 卡里，存 localStorage。

## 四个 agent 工具

这四个是标准 agent 工具，注册在有工具权限的会话里，模型可按需自动调用：

| 工具 | 一句话 | 什么时候用 |
| --- | --- | --- |
| `sysinfo` | 查 OS / CPU / 内存 / 网卡 / 主机名，CPU 使用率两次采样计算 | "这台机器什么配置" |
| `encoding_run` | 自己 spawn 命令、接原始字节，识别 UTF-8 / UTF-16LE / GBK / GB18030 / Latin-1 后正确解码 | 命令输出中文乱码时 |
| `token_cost` | 按 tokenMeter 同款密度启发式估算常驻上下文开销 | "上下文被什么吃掉了" |
| `config_conflicts` | 扫重复指令段落、同名 Skill、工具名冲突 | "有没有重复指令 / Skill 重名" |

`encoding_run` 解决的是一个真实痛点：DSH 核心把命令输出按 UTF-8 解码（`toString('utf8')`），GBK 中文会变成不可还原的乱码。这个工具绕开核心，自己接原始字节再按检测到的编码解码。

`token_cost` 实测样例（150 个工具 schema + 60 条 Skill 摘要 + 1 个 AGENTS.md）：常驻上下文约 **46,196 tokens**，其中工具 schema 占 37,632、Skill 摘要占 8,436——装得越多，这块越重。

## 怎么运行四个工具

两种路径，结果都在**会话里**看，不在设置页弹：

1. **自动**：agent 看到工具描述，遇到匹配场景自己调用（跟调 `ops_bash` 一样）。
2. **手动**：设置页 🛠️ 卡片点「运行」= 往当前主会话发一句「请用 X 工具……」，`queue` 模式入队，agent 随即可调用，结果写在该对话。也可在对话里直接说「用 token_cost 统计一下」。

> 为什么结果不内嵌在设置页：本包是静态 pnpm-link 插件，浏览器半区拿不到 `host.call`（那是 dynamic 插件专属）；做内嵌结果面板要另造一条 Typert Remote，成本高且脆。所以选了最稳的"发消息到当前会话"。

运行按钮在对应 master 开关关闭时变灰；需要先打开一个会话（主视图会话按 `retainedBy.mainView > 0` 判定，与 DSH 自身一致）。

## 已知边界

诚实说明，避免误解：

- **通知**：只在任务结束那一刻触发；"始终"不是"一直弹"，而是"结束时无视焦点也弹"。窗口关掉时客户端不在，通知不会发。点通知跳会话在窗口开着/后台时有效，最小化拉不回、DSH 关掉不启动。**Agent 等待提醒靠官方卡片 DOM 标记识别，官方改标记后可能失效；且因最小化时 webview 的 JS 被节流，窗口最小化期间不弹，切回窗口后补弹**。
- **encoding_run**：只救**新执行命令**的输出；已经进 Harness 变成 U+FFFD 的乱码无法还原。它自己 spawn 进程，不继承内置 bash 的沙箱、审批和后台任务机制，权限与 DSH 本身相同——**只跑你信任的命令**。
- **token_cost**：是 `ceil(chars/4)+4` 密度启发式，不是精确 tokenizer、不是按类别计费。Skill 正文默认不全量进上下文（只算目录摘要 + 被调用的正文），报告里标注了常驻 vs 按需。
- **config_conflicts**：查的是机械重复（trim 后字节级相同的段落、同名 Skill / 工具）；措辞不同但语义矛盾的冲突抓不到。扫描范围是当前工作目录往上到项目根 + 用户全局 AGENTS.md。
- **sysinfo**：`node:os` 拿不到网络收发流量字节（rx/tx），只能列地址 / MAC；要流量需另装 `systeminformation`（本项目未装）。
- **自动续作**：表现为用户气泡；页面关掉不生效；goal 活跃时的让路逻辑未做。
- **引用角标**：本版 DSH 的脚注 / `<details>` 不可点，只能用 Markdown 链接；点开是跳走不是就地弹。模型必须真的检索到来源才会贴，通用常识不贴。
- **远程巡检**：只读状态 + 立即重连 + 看门狗；修不了凭据/进程级故障，也拉不起最小化窗口。
- **语音输入**：借官方 bundle，需先启用并下好模型；靠 aria-label 定位官方按钮，官方 DOM 变了可能失效；窗口失焦会取消录音；录在别的对话标签的通知，本标签拦不住（标签间状态独立）。
- **Ctrl+点击外部打开**：靠文件卡片 `data-presented-file` 标记与正文链接 `title` 路径识别，官方改了这两处 DOM 就退回右侧栏预览（无害）。用系统关联应用打开，能否打开取决于该文件类型的系统关联。

## 目录结构

```text
dsh-toolbox-gjkt/
├── index.js              # Host half：Config schema + 注册四个工具 + 引用角标系统提示词
├── client.js             # Client half：通知状态机、划词工具栏、设置页 UI、远程巡检、语音快捷键
├── tools.js              # 四个 host agent 工具的实现
├── cordis.patch.yml      # bundle patch + 默认 config
├── package.json
├── locale/
│   ├── en.json
│   └── zh.json
├── docs/
│   ├── DETAIL.md         # 详细使用说明
│   └── REMOTE-GUARD.md   # Windows 远程守护配方（任务计划程序，未自动执行）
├── icon.svg
├── LICENSE
└── README.md
```

技术选择两点：

- 四个工具用**手写 raw JSON Schema** 定义注册（`tools.js`），零外部 import 依赖——绕开 profile 里未必装了 `dsh-tools` 的问题。
- 通知/工具栏/续作/远程/语音全在**客户端**做：DSH 核心已把会话生命周期事件转发到浏览器，不需要自建 Host RPC，也不用轮询。

## 卸载 / 回滚

- **临时停用**：设置 → 工具箱，把对应 master 开关关掉（即时生效，不卸载）。
- **整个卸载**：插件管理器里禁用/移除 `dsh-toolbox-gjkt`，或删除本插件源码目录后重新安装。
- 配置存在 DSH 原生 Config 里，卸载即随之移除；仅看门狗、语音、静音掐断、Agent 等待提醒、Ctrl+点击外部打开这几个开关留在浏览器 localStorage（无害，可忽略）。不污染主对话框。

## 安装前必读

- **依赖**：`@deepseek-ai/schemastery ^3.19.0` 已在 `package.json` 声明，由 DSH 的插件管理器安装时自动解析，无需手动处理。
- **环境**：在 `@deepseek-ai/dsh-desktop-runtime` 0.2.2-rc.5 上开发验证；通知/工具栏/续作依赖 web 客户端的会话事件转发，agent 工具需要会话有工具权限；语音输入需另启用官方 voice-input bundle。
- 功能本身不联网、不外发数据；搜索/翻译只是打开对应网页，编码工具只跑你给的命令，语音识别在 Host 本地 CPU 完成（仅下载模型时联网）。
